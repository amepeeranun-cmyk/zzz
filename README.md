# Blood Cell Insight

หน้าเว็บสำหรับคัดกรองภาพสเมียร์เลือดด้วยโมเดล Roboflow `my-first-project-cp4zt/1` ที่อ้างอิงจากโน้ตบุ๊กในโฟลเดอร์นี้

## วิธีใช้

1. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์
2. เลือกภาพจาก **อัปโหลดไฟล์** หรือเลือกภาพที่เคยใส่ไว้ใน **เลือกจากคลัง**
3. กด **วิเคราะห์รูปภาพ** และวาง Roboflow API key ของคุณเมื่อระบบถามครั้งแรก

ภาพจะถูกแบ่งเป็น 9 ส่วนก่อนส่งเข้าตรวจ เพื่อให้พฤติกรรมสอดคล้องกับโน้ตบุ๊กเดิม ผลลัพธ์ที่แสดงคือจำนวนวัตถุที่ตรวจพบทั้งหมด, จำนวนที่เป็น `Ehrilchia canis`, เปอร์เซ็นต์การติดเชื้อ และระดับผล:

- ไม่พบ: ไม่มีเซลล์ติดเชื้อ
- ระดับต่ำ: มากกว่า 0% ถึง 5%
- ระดับสูง: มากกว่า 5%

API key จะเก็บใน local storage ของเบราว์เซอร์เครื่องนั้นเท่านั้น และไม่มีการใส่คีย์ลงในซอร์สโค้ด
